## 版本摘要列表 (Summary)

### [v2.11 (Build 2.11.0.1)](changes/v2.11.md) - 2026-10-05
- **版本对齐与开源同步**：统一版本规范为 2.11.0，GitHub 自动化同步分支升级为 `dev/v2.11`，并新增演示站发布与全套脱敏配置指引；
- **测试门禁健全**：全量接入 Vitest 5 自动化测试体系，覆盖核心工具函数，保证构建无回归；

- **排版体验升级**：支持文章摘要 Markdown 富文本实时渲染、插图点击全屏放大（medium-zoom）与 Mermaid 架构图渲染；
- **资源路径自愈**：实现 FrontMatter 相对路径图片自动重写为绝对路径，消除首页 404 碎图；
- **智能避让机制**：正文页自动检测摘要图片并隐去顶部摘要块，消除正文首图重复；
- **权责隔离与纯粹声明式**：确立 public/ 与 posts/ 严格权责边界，彻底剔除底层流式中间件与跨目录拷贝钩子，合规审计门禁零容忍拦截；
- **流量与分析管理**：接入 Google Analytics 4 与 AdSense 原生静态配置，支持全站指标分析与变现展示；
- **工程调优**：提升 Rollup 警告阈值至 1000 KB，彻底消除本地调试白屏与依赖兼容性问题。
