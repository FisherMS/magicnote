# Version 3.0

## Build 3.0.0.1 (20261017.1)

### Added
- **开启多主题架构体系 (Multi-Theme Architecture)**：重构 `.vitepress/` 目录组织，确立“共享业务内核 (Shared Core) + 多主题物理隔离 (Pluggable Themes)”的工程规范，支持未来演进完全不同的布局与视觉体系。
- **编译期按需主题分发器 (Theme Dispatcher)**：实现 `.vitepress/theme/index.ts` 动态解析机制，通过构建环境变量 `VITE_BLOG_THEME` 在打包期静态装载目标主题，实现非激活主题代码物理级 Tree-shaking 剔除，保持零前端体积冗余。
- **极简主题 (Minimal Theme) 样板落地**：新建 `.vitepress/themes/minimal/`，包含专属单栏布局（`MinimalLayout.vue`）、极简流式列表（`MinimalPage.vue`）与纯净样式系统（`minimal.css`），验证并走通全新版本布局的扩展链路。
- **多主题开发接入指南**：编写 [theme-development-guide.md](../theme-development-guide.md)，明确主题契约接口、目录布局规范与数据流消费方式。
- **复合与独立构建脚本**：在 `package.json` 中新增 `dev:minimal` 与 `build:minimal` 命令，支持按主题独立启动开发调试与静态 SSG 生成。

### Refactored
- **业务内核与呈现层彻底解耦**：抽离 `.vitepress/core/` 目录，将文章元数据抓取与分页生成（`serverUtils.ts`）、日期标准化（`date.ts`）、分页算法（`pagination.ts`）、Markdown 摘要解析与图片探测（`functions.ts`）统一收敛至共享内核，杜绝重复实现。
- **默认主题平移与封装**：将原有单体主题封装为独立的 `.vitepress/themes/default/`，作为标准开箱即用的经典博客主题。
- **零破坏性向下兼容 (Zero-breaking Proxies)**：在原 `.vitepress/theme/` 与 `.vitepress/theme/components/` 路径提供完整的 Re-export 导出与组件透明代理，保证原有 22 个单元测试以及历史 Markdown 页面无需任何路径改动即可无缝运行。

### Changed
- **版本号跨越升级**：正式升级版本为 `3.0.0`，对应规划版本 `v3.0` 与流水线构建号 `Build 3.0.0.1`，标志着博客系统由单体主题正式迈入多主题时代。
